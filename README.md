# AttendanceIQ Pro — Academic Attendance & Schedule Copilot

A comprehensive, client-side academic schedule and attendance tracking system tailored for **Mohammed Shakib (CSE AI & ML, II B.Tech, Sphoorthy Engineering College,**.

## 🚀 Features

- **Overview Dashboard**: Circular Attendance Radial Gauge, live lecture radar with real-time class tracking, and instant day actions.
- **Daily Attendance Logger**: Interactive date picker and lecture logging with 12-hour format and lunch recess intervals.
- **Course Matrix & Academic Ledger**: Comprehensive breakdown of all 6 enrolled subjects (SE, COA, OOP, NJ, DBMS, MFS) with safe bunk limits and recovery deficits.
- **AI Risk Copilot (Advisor)**: Predictive trajectory modeling and shortfall mitigation strategies.
- **What-If Scenario Simulator & Goal Solver**: Calculate consequences of missing lectures or consecutive attendances before taking leaves.
- **Telangana Academic & Holiday Calendar**: 2026 gazetted holidays pre-loaded with monthly statistics.
- **Master Academic Timetable**: Weekly schedule matrix for Room MV 308.
- **Milestones & Achievements**: Badges and streaks tracking.
- **Offline Data Storage & Portability**: 100% client-side `localStorage` data persistence with JSON export and import.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Custom Design System with Glassmorphism & High-Contrast Tokens)
- JavaScript (ES6+ Vanilla Engine)
